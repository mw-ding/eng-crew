# truth: later slices extend this file when their docs land.

# Formats (one per line; blank lines and lines starting with `#` are ignored):
#   path/to/file.md                      the file must exist
#   path/to/file.md :: ## Heading text   the file must contain this exact
#                                        heading line (outside code fences)
#
# Keep the entries sorted (byte order of the whole line), one per line, with
# no comments between them: a new doc then lands at its own place in the file
# instead of at the end, where every PR appends and so conflicts (#325).
# check-repo.py fails on an entry that sorts before the one above it.
