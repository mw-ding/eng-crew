**Breaking:** Release 6.0.0 is the one major cutover for the modular layout (M31: #1222, #1223, #1224, #1225, #1236), so installs and packs that name old paths must move to the new ones. Old to new paths: `scripts/crew` is `cli/crew`; `scripts/crew-config.py`, `scripts/crew-render.py` and `scripts/crew-roles.py` are under `core/`; `scripts/crew.d/*` is `environments/terminal/crew.d/*`, `scripts/crew-session.py` and `scripts/crew-proc.py` are under `environments/terminal/`, `scripts/crew-remote.py` is `environments/terminal/remote/crew-remote.py` and `scripts/session.d/<backend>.py` is `environments/terminal/sessions/<backend>/adapter.py`; `scripts/crew-harness.py` is `harnesses/crew-harness.py` and `scripts/harness.d/<engine>.py` is `harnesses/<engine>/adapter.py`; `scripts/crew-repo.py` is `connectors/github/crew-repo.py`; `packs/github/manifest.toml` is `connectors/github/manifest.toml`; and `scripts/test-*.py` is `dev/tests/<module>/test-*.py`. Shims: through every 6.x release each of the 56 moved script paths stays a compatibility shim that runs the moved file (so `scripts/crew`, `$CREW_BIN`, the Stop hook and the remote forced command keep working), an adapter left in `scripts/harness.d/` or `scripts/session.d/` is still discovered, and `packs/github/manifest.toml` stays a copy of the connector's manifest; tests have no shim, and `run-tests.py` accepts a bare test name. The shims, the old adapter discovery and the `packs/github/` copy are removed in 7.0.0, the next major release (team spec REQ-23: one major version). Pack updates: a pack's own code (connectors, harness adapters, environment defaults, skills) now loads through a `pack.toml` whose `framework` range must include the installed release, such as `">=6.0.0, <7.0.0"`, since bootstrap and upgrade refuse a pack whose range excludes it; run `crew pack test <dir>` in the pack's CI. Migration: before 7.0.0, point profiles, wrappers, hooks, `CREW_BIN`, remote forced commands and pack docs at the new paths; move a harness adapter kept in `scripts/harness.d/` into the pack as `harnesses/<name>/adapter.py`, declared under `[provides]` in its `pack.toml`; read the GitHub manifest from `connectors/github/`; and widen any `pack.toml` range that stops below 6.0.0.
