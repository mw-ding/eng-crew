Release 7.2.0 brings a trustworthy runtime and usable throughput (M36). `mdstack doctor` now catches a half-finished install: a checkout whose `origin` names another repo fails its `checkout` row and stops `mdstack up` (#1323), and a `claude role trust` row checks Claude Code folder trust for the checkout role worktrees come from (#408). Capacity and progress hold up: a fresh builder spawn ends its own build reservation (#1266), a builder whose `build` nudge was never acked counts as idle once its `done:` names the issue (#1302), and `mdstack watch` reports a run whose pane has printed nothing for `--idle-stall` seconds as stalled (#1283). Review state and run generations stay safe: a reviewer engine is read from every `Engine:` line (#442), another runtime's markers no longer suppress this runtime's reviewer pass (#1290), the approved and changes state tags render on one line each (#823), a reviewer done line with a trailing note routes like the bare line (#1343), a retained status file is no longer replayed as fresh wakes (#819), and a queued researcher wake reaps only the run that wrote it (#1092). Post-land close-out keeps the synthesizer through the default-branch CI run (#1339) and closes linked issues GitHub's auto-close missed (#846). `mdstack watch` runs its `--source` polls at most once per `--source-interval` and backs off on a rate limit, so a shared GitHub login keeps its quota (#1300). The bootstrap suite runs 58 cheaper tests instead of 97 (#1333). The watcher's gateway-error match counts only a harness's own error line (#1366). A builder now builds every merge train while the synthesizer keeps landing (#1391). CI hardening: the changelog check refuses a fragment whose `pr:` is `TBD` or another PR's number (#1257), and the `links` job retries a cached, pinned lychee download (#1352). Also in this release: the M20.1 host OS adapter contract and lab test-host image (#1355, #1356), a team file's per-repo `checkout` (#1287), a private-state `docs-scan.py --ref` (#1320), the memory changelog exemption (#1386), campaign A22/A23 oracle fixes (#1177) and M35 core memory (#1377). No breaking changes; upgrade a 7.1.0 install with `mdstack upgrade --version v7.2.0`.
