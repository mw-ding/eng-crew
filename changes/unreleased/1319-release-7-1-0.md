Release 7.1.0 brings the user-level install (M35). Everything mdstack installs now lives in one root, `~/.mdstack/` (`config.toml`, `releases/`, `bin/`, `state/`, `runs/`, `live/`), with only the repo checkout outside it (#1316). The user-level `~/.mdstack/config.toml` is the default config, so `mdstack` commands need no `--project`; a project-level `config.toml` passed with `--project FILE` stays the secondary option for a separate project-group stack, and the two never merge. `mdstack install` puts a stable `mdstack` launcher on your `PATH`, and `mdstack upgrade --version vX.Y.Z` or `--latest` upgrades it in place: fetch and verify into `releases/`, re-render every project, then flip `releases/current`, with rollback to the bundle already on disk (#1317). A second crew can share the machine under its own root with `CREW_ROOT` and its own launcher name (#1324). Also in this release: role emoji on tmux and herdr tabs (#1157), an optional `identities.team` name for the coordinator window (#1329), the crew session on the owner's default tmux server (#1327), the full thirteen-label `crew:*` set in bootstrap and doctor (#1322) and an optional project board (#1328). Upgrading a 7.0.0 install: reinstall it fresh under `~/.mdstack/` (`docs/guides/getting-started.md`); there is no fallback to `crew.toml` or the old `~/crew-home/` and `~/.crew/` defaults.
