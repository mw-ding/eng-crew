Release 7.5.0: periodic reflection over learnings (M39). The protocol now reflects on its own record and proposes fixes, without approving them itself. The reflection contract and authority boundary in `docs/self-improve.md` (#1517), the deterministic evidence scan `scripts/reflection-scan.py` (#1518) and the effect measures `scripts/reflection-measures.py` (#1524) shipped in 7.4.0; this release completes the loop. The researcher's `protocol-reflection` procedure posts one ranked, evidence-linked report per window (#1519), run as `mdstack spawn researcher --reflection` with its run ID, log issue, input SHA and window carried through the cap queue, dequeue and restart (#1520). Opt-in `[reflection] enabled` schedules a weekly reflection and one per closed milestone, and `mdstack reflection` prints the ledger (#1521). `scripts/reflection-candidates.py` files recurring-pattern cards with Decision `pending`, never approving them (#1522). The coordinator relays one digest per report, records each decision, and turns accepted proposals into normal build issues (#1523). `scripts/reflection-effects.py` evaluates every accepted proposal in later reports and recommends keep, revise or revert (#1525). Also in this release: on a session profile `mdstack up` starts (or attaches to) the interactive coordinator instead of refusing it as not tmux (#1548), and campaign scenario A29 drives the handoff round trip between two full teams (#1441). No breaking changes; upgrade a 7.4.0 install with `mdstack upgrade --version v7.5.0`. Reflection stays off until a profile sets `[reflection] enabled = true`.
