Release 7.10.0: M48, release integrity and consistent reports, then M46's close-out and all of M47; 7.9.0 is skipped. **Breaking:** a release cut PR now links its release issue with `Refs #N` plus one whole line `Release issue: #N` instead of `Closes #N`, so landing the cut no longer closes the issue before publication, which changes how the Linked issue merge gate is satisfied for a cut (#1416); the owner chose a minor for it. Migration: write a cut PR body with `Refs #<release issue>` and the `Release issue: #<release issue>` line, not `Closes`; installs need no edit. M48, release integrity and consistent reports: a release cut refuses a minor or patch that breaks the published predecessor's pack manifests (#1415), released CHANGELOG sections are immutable (#1417), moved or quoted prose keeps its qualifiers with the `check-pr-linkage.py` allocation check (#1418), one outcome-first report skeleton for every role with the team in signatures (#431, #1291), work-unit issues with one PR each (#978), the auto-apply deadline never supplies a merge-ok (#258), the coordinator's owner-config authorization rule (#372), the `examples/agentconnect/` example removed (#1314), the M48 spec slice (#1697) and the M48 status sync (#1721). M46 close-out: the campaign lint's one termination model (#1684) and the M46 status sync (#1690). M47: a bootstrap re-run with nothing changed writes nothing (#1090), team-file `#<repo>` references bootstrap the selected repo (#1344), briefs read core memory at the remote default branch (#1537), `mdstack connect` uses the host `address` (#1595), the repo guard stays out of the bundle (#281), builder runs own their Git metadata and can run confined, with the new `runtime.options.confinement` (B5, #1252; its live confinement proof moved to #1739), the new `mdstack gc` merged-only worktree sweep, also run by `mdstack route` on each backstop wake (B6, #316), the M47 spec slice (#1691) and the M47 status sync (#1735). Upgrade: from 7.8.0, `mdstack upgrade --latest --yes` applies as before; `runtime.options.confinement` defaults to `off`, so no profile edit is needed (an unconfined builder gets a `mdstack doctor` warning), and only how a cut PR body is written changes (#1416).
