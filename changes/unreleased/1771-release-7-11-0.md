Release 7.11.0: M49, responsive runs and attributable failures, then M50, portable session contracts and stack binding. **Breaking:** protocol §7 gains a runtime-bound "No project pause" gate row with the new `mdstack pause` and `mdstack resume`, a work pause that keeps the coordinator and the watcher running while every other window stops and every gate that starts work refuses (#1714). Migration: none; an install with no `pause.json` behaves as before. **Breaking:** on the session runtime the researcher triage sweep is opt-in, so an unset `runtime.options.researchers` now defaults to `0` (#1724). Migration: a session profile that runs the triage sweep, including one with `triage.enabled = true` that relied on an omitted cap, sets `runtime.options.researchers` to a positive value, for example `researchers = 1`; tmux keeps its default of 2. The owner chose a minor for both. M49, responsive runs and attributable failures: the lead backstop backs off unchanged demand and honours typed `waiting:` lines (#1715), a builder's `[<Builder>/merge-up]` note starts its delta re-review (#1682), the builder lead completes a lifecycle reclaim with its pool's kill (#1701), `mdstack dequeue` names a lead-managed pool instead of `no free slot` (#1100), `RemoteRun` spawn tests refresh the runner heartbeat (#1659), bootstrap smoke tests pin the host sandbox probe (#1668), a watcher gone before SIGTERM counts as stopped (#1757), the M49 spec slice (#1748) and the M49 status sync (#1768). M50, portable session contracts and stack binding: a primary host on a command checkout (#1723), the configured specs home with the new `[docs] specs_external` (#1725), a VCS-neutral negative-control requirement (#1726), the one-time session bootstrap step in the session upgrade guide (#1727), session stack land by top change with revision ids and per-change readback (#1722), the M50 spec slice (#1749) and the M50 status sync (#1769). Upgrade: from 7.10.0, `mdstack upgrade --latest --yes` applies as before; only a session profile that runs the triage sweep needs the `researchers` edit (#1724). From 7.6.0, the same command applies without `down`/`up` (#1618); a profile without `[ci] required_checks` keeps its CI behaviour (#1536), `runtime.options.confinement` defaults to `off` (#1252), and a cut PR body uses `Refs #N` plus `Release issue: #N` (#1416).
