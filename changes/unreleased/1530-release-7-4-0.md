Release 7.4.0: portable installs honor their declared contracts (M38). Portable installs: a pack outside a git checkout passes the install pin through its `pack.toml` `[vcs]` `clean` and `commit` commands (#1326), a backend map's `[ids]` admits `marker_key` and carries it into the resolved ids (#1031), and `mdstack doctor` checks `gh` only when a concern binds the `github` backend or the release source is `github`, so an all-own-backend pack bootstraps with no `gh` (#1123); this completes the pack floor scan scope (#1325) and git-free evidence provenance (#1330) that shipped in 7.3.0. Session runtime parity: the session synthesizer lands each ready PR alone instead of copying the tmux train recipe (#1041), owner-present caps `present_builders` and `present_reviewers` (#1053), `researchers = 0` as a no-op (#1057), and `mdstack host check` and `host prepare` for a session profile (#1122). Render checks and headroom: a render note for a role the runtime does not render fails the render (#1054), and `crew-render` reports each brief's `size_budget` headroom and warns within 5% of it (#1056). Release safety: a cut PR can no longer land on a stale merge ref, and fragment PRs hold while a cut is open (#1433), and the owner can record a standing release delegation for cut PRs (#1435). M39's first pieces: `scripts/reflection-scan.py` builds a deterministic reflection evidence index (#1518), and reflection effect measures with `scripts/reflection-measures.py` (#1524). Also in this release: the two-host dry run recorded as met on a simulated host (#209). No breaking changes; upgrade a 7.3.0 install with `mdstack upgrade --version v7.4.0`. One check is stricter: a profile with a `runtime.options.notes.render.<role>` entry for a role its runtime renders no brief for (for example `researcher` under `session`) now fails `crew-render` naming the key; remove that entry before upgrading.
