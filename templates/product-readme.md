# Product README seed

Seed README for a product or prove-it repo onboarded to the crew. Copy the
block below to the repo's root `README.md`, replace every placeholder, and
delete these instructions. A repo that already has a README with the same
sections can keep it. Keep the tone concrete and short; no secrets, tokens or
box paths.

````markdown
# <product-name>

## Problem

<Who has the problem, and what it costs them today. Two or three sentences.>

## What it is

<What this repo builds, in plain words. Name the main parts and what is out of
scope.>

## How to run / use

<Install, run and test commands a new engineer can copy. Include a minimal
usage example or screenshot.>

## How the crew works

Changes land through a bot crew: spec, build, CI, review, merge. Roles,
stages and the merge gate are in the
[mdstack protocol](https://github.com/mw-ding/mdstack/blob/main/docs/protocol.md).
Open an issue with numbered acceptance criteria to request a change.

## Status

<Current state (for example prototype, beta), what works, what is next, and
the date of this update.>
````
